## What It Does

Draw My World converts uploaded images into Minecraft Bedrock Edition pixel art made from blocks. The browser tool compares image colors against Minecraft-compatible palettes and builds command block chains that can be placed in-game.

Image processing and command creation take place locally in the browser. The utility also provides a live result preview, editing controls, and export functions so you can refine the conversion before using it in Minecraft.

## Features

- Transform imported images into Minecraft block pixel art
- Create command block chains for placing the artwork in-game
- Process images locally in a web browser
- Select from palette presets and different color-matching metrics
- Control quantization to suit various image styles
- Apply dithering for different visual patterns and results
- Inspect edits through a live preview
- Export the generated command results for storage or sharing

## Frequently Asked Questions

### How can I use the tool?
Open the project in your browser, upload an image, configure the conversion options, and export the result.

### Can I make changes after importing an image?
Yes. Palette settings, preview options, and conversion behavior can be modified before exporting another version.

### Are my images uploaded to a server?
The tool is intended to perform image processing locally in the browser rather than sending files to a server.

### Which images are most suitable?
Images with clear contrast, simpler shapes, and a pixel-art-friendly appearance generally convert more easily. Other artwork can also be tested.

### What output settings can I change?
You can modify palette presets, color matching, dithering, and quantization to influence the resulting Minecraft build.

### Does this support every Minecraft edition?
The project is intended for Minecraft Bedrock Edition. Verify the output against the Bedrock setup where you plan to use it.

### Where does the exported output go?
The save location depends on your browser and the export method you select. Follow your browser's download behavior or use the project's export tools to save the generated files.
